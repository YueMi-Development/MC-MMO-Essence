# MC-MMO-Essence

Essence/energy system for PaperMC servers. Template project - needs implementation.

## Stack
- PaperMC 1.21+, Java 21, Gradle (Kotlin DSL)
- Dependencies: Paper API, YueMiLibs

## Conventions
- Packages: `org.yuemi.mmoessence.{api,plugin}`
- Classes: PascalCase, `*Api`, `*Provider`, `*Impl`, `*Plugin`
